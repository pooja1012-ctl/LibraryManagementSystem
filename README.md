# Library Management System

A console-based Library Management System developed using Core Java. This project demonstrates object-oriented programming, file handling, and modern Java features.

## Features

- Add and display books
- Search books by ID and title
- Register and display library members
- Issue and return books
- Display available books
- Save and load data using text files

## Java Concepts Used

- **OOP:** Classes, objects, and encapsulation
- **Inheritance:** `Member` extends `Person`
- **Interfaces:** `Library` implements `Searchable`
- **Lambda Expressions:** Using `forEach()` to display books
- **Stream API:** Filtering available books
- **File I/O:** Reading and writing book and member records
- **Exception Handling:** Handling file-related errors

## Technologies

- Java
- Eclipse IDE
- Java Collections (`ArrayList`)
- Java File Handling

## How to Run

1. Clone or download this repository.
2. Import the project into Eclipse as a Java project.
3. Locate `LibraryManagementApplication.java` inside `src/library`.
4. Run the class as a Java Application.
5. Follow the console menu.
