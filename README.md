# Library Management System

A console-based Library Management System developed using Core Java.

## Features
- Add and display books
- Search books by ID and title
- Register and display members
- Issue books to members
- Return books
- File handling for saving and loading records

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- Exception Handling
- File Handling (FileReader, FileWriter, BufferedReader, BufferedWriter)

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse.
3. Run `LibraryManagementApp.java`.
4. Follow the console menu.
